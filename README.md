# Detección de Daños IA — Frontend

Demo/cliente que consume el backend de detección de daños
(`detecciondanosiavback`) vía HTTP. No carga ningún modelo directamente —
solo sube una foto y muestra el resultado que devuelve la API real.

## Estado

En construcción. Demo actual: Streamlit, primera categoría cubierta
comedores.

## Gitflow

Este repo sigue gitflow: `main` (estable), `develop` (integración), ramas
`feat/*`/`fix/*` desde `develop`, PR contra `develop`.
